# 嵌入式导论

2026-06-26 周五 ☀


今天就要结课了，实验还没有做出来。上了15节课，有几次缺课，自己还是不能够理解 STM32 的工作原理, 刚开始实验写代码仿真真的很茫然，什么都不会。没有课本，没有完整的代码示例，第一个参数选项也不是很理解为为什么这样那样选择，在 github 代一些代码来运行，却发现很多都是基于 keil5, 而自己装的是 keil4, 再加上各种各样的报错，真的很考验耐心。而且自己又用平板做为主力，没有 Windows 真的像是脱离课堂。   

还好，通过豆包和网上资料找到了可行性代码和软件。起初在 Termux 上编译 Stlink 可行，但是编译 gcc-none-eabi 就失败，于是转用 proof-distro 容器安装的 Ubuntu 编译 gcc-none-eabi 成功，就在欣喜万分时，又焊接了 stm32t8c6 引脚，不小心右手食指碰到了焊头(wu~~)。当 st-link 通过 usb 转接线插入平板，在 ubuntu 输入 lsusb, 返回错误即无法识别 usb 设备，在 Termux 输入 termux-usb -l 可以识别，但是 st-info 会找不到，似乎是 st-info 寻找 usb 方式在平板上没有权限，而 Termux 上只有通过 termux-usb 来获取，并且看到程序通过调用 api 获取 usb 设备信息，于是想通过类似方法修改 stlink 源码重新编译，但不知修改哪里，根据豆包提示和返回修改代码，重新进行了编译，结果还是识别不到设备。  

最终还是放弃了在 Termux 上烧录了，于是把目光移到了 raspberry pi 3b+ 上，已经好久没用了，于是又重新打开，安装 stlink, 插入 stm32, 识别成功， 烧录成功！

硬件问题解决了，之前使我困惑的还有在 keil平台 stm32 文件目录结构，库从哪里引用的，为啥要有那么多文件夹, 主要问题是之前用工程文件编译后查看 locgic 分析时会报错，当时也不知道代码怎么写，使用哪个接口才能看到波形图。而且自己又在 Termux 上编译等待。最终找到有人有同样想法要在 ubuntu 进行开发，于是克隆了[项目](https://github.com/24-Fahed/stm32-arm-gcc-example.git)， 使用 make 编译， 成功！

之前让豆包写的在 stm32t8c6 用 p13 引脚小灯来测试，在 keil4 上几经挫折后， 后来参照原子学习单片机的资料和下载源码(ps，因此开通了某度网盘，哎，为了学习资料)，装了 keil5, 测试原子学习的代码，编译虽然成功，但还是不知怎么看到波形图，几经看视频，终于有一个 up 主也用原子的代码，照着操作，将引脚检测设为 GPIOB_IDR.5 后，成功输出波形图了！

接下来就是在 keil4 烧录到 stm32t8c6, 其中也遇到问题，经过一些选项勾选，最后还是成功烧录，p13小灯亮了起来。最后在树莓派上使用 st-flash 也成功烧录。

学习 stm32 的开始阶段总是解决了，后面将要学习更多理论和开发，做一些有趣的项目，目前第一个要解决的就是在树莓派上通过 ros2 来和 stm32 通信(btw, 在树莓派了也安装了 ubuntu 26.04 版本和 ros 2), 接下来就是写代码编译了....
